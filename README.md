# 🌱 PlantiVerse: Planting @ UKM Botanical Garden

A VR-based interactive planting game developed as a multimedia project at Universiti Kebangsaan Malaysia (UKM).

## 📖 About the Project

**PlantiVerse: Planting @ UKM Botanical Garden** is an interactive VR planting game that allows players to explore a virtual botanical garden environment and learn about different plants through game-based challenges.

Players are presented with mystery boxes containing different seeds. They can use the hint system to identify the correct seed, grab the selected seed, and place it into the corresponding planting plot. Correct answers display the associated plant and information while awarding points to the player.

The game consists of **five planting challenges**, with the player's performance displayed on the final score screen.

## 🎮 Gameplay

The main gameplay flow is:

1. Enter the virtual botanical garden environment.
2. View the game rules from the signboard.
3. Interact with mystery boxes to obtain hints.
4. Select and grab a seed.
5. Release the seed into the planting plot.
6. The system checks whether the selected seed is correct.
7. Receive feedback for the answer.
8. Earn points for correct planting.
9. Complete all five challenges.
10. View the final score and performance message.

## 🧩 Main Systems

### Farm Game Manager

Manages the overall scoring system and tracks the player's progress throughout the game.

When a player correctly plants a seed, points are added to the total score. Once all five planting challenges are completed, the final score panel is displayed together with a performance message.

### Farm Plot

Handles the planting area for each challenge.

The system checks whether the selected seed matches the correct answer. A correct seed displays the corresponding plant and information panel, while an incorrect seed triggers a warning and wrong-answer feedback.

### Seed Identity

Identifies the type of seed selected by the player.

The system supports predefined seed categories such as:

* Rose
* Daisy
* Sunflower
* Durian
* Mangosteen

Different plant types can provide different point values for the scoring system.

### Checkpoint Manager

Controls the hint system.

Each challenge contains three mystery boxes that provide clues about the hidden seed. Once a mystery box is interacted with, the corresponding hint is displayed and the interaction is disabled to prevent repeated use.
